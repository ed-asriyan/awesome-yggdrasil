# Archive

Projects related to Yggdrasil that are archived, deprecated or no longer actively maintained. They are kept here for reference and are not part of the main [list](README.md).

- [Crispa Android](https://github.com/yggdrasil-network/crispa-android) - Community-contributed Android client. Archived in January 2023.
- [HyperModem](https://github.com/popura-network/HyperModem) - Open source firmware for fast deployment of mesh nodes. Last updated in January 2022.
- [PopuraDNS](https://github.com/popura-network/PopuraDNS) - DNS server with decentralized domain names support. Last updated in November 2021.
- [Yggdrasil iOS](https://github.com/yggdrasil-network/yggdrasil-ios) - Reference client for iPhones and iPads. Last updated in June 2024.
